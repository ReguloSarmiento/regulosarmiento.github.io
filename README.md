# Regulo Sarmiento - Senior Android Developer Portfolio

Personal portfolio website showcasing over a decade of native Android engineering, enterprise SDK architecture (Zendesk), consumer applications (Bamboo, Flipdish, Bupa Boost), and modern Jetpack Compose / Kotlin Coroutines expertise.

---

## 🚀 How to Run Locally

You can run this website locally on your Mac using any of these simple methods:

### Option 1: One-Click Script (Recommended)
In your terminal, run:
```bash
cd ~/portfolio
./run.sh
```
This will automatically start a local server at `http://localhost:3000` and open your default browser.

### Option 2: Using NPM
```bash
cd ~/portfolio
npm start
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Instant Browser Open (Zero Server)
```bash
open ~/portfolio/index.html
```

## ✨ Key Portfolio Features

* **Interactive Hero Showcase:**
  * **Compose UI View:** Live interactive messaging SDK simulation with interactive response chips.
  * **Kotlin SDK Code View:** Syntax-highlighted MVI / StateFlow / Coroutines clean architecture snippet.
  * **Architecture View:** Visual modular SDK layering diagram.
* **Impact-Driven Experience Timeline:** Detailed breakdowns of roles at **Zendesk**, **Flipdish**, **Bamboo App**, **Trust5 (Bupa Boost)**, and freelance foundations.
* **Filterable Capabilities Matrix:** Interactive category filters for Kotlin, Compose, Clean Architecture, DI, Testing, CI/CD, and AI tools.
* **Download CV Button:** Direct link to download `Regulo_Sarmiento_Resume.pdf`.
* **Direct Contact & Fast Actions:** One-click email and phone copying with toast feedback, direct mailto draft generation, and social links (LinkedIn, GitHub).
* **Dark / Light Mode Toggle:** Seamless theme switcher with persistent local storage.
